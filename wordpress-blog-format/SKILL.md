# WordPress Blog Format

Use this skill to produce blog articles in the user's preferred WordPress-ready format, learned from the sample `how-to-use-sora-2-on-pc-wordpress-copy.html`.

## Core Workflow

1. Determine whether the user wants:
   - a complete WordPress copy page,
   - only the article body,
   - an SEO rewrite/optimization of an existing article,
   - or a content brief/outline.
2. For complete drafts, use the module order in `references/copy-page-pattern.md`.
3. Separate editor instructions from publishable body:
   - Yellow/guide notes: Chinese publishing instructions, image placement, alt text, captions, source handling.
   - White/copy boxes: clean English article content intended for WordPress.
4. Keep claims careful and time-bound. Avoid absolute promises such as "always available", "officially guaranteed", or "permanent access" unless a source proves them.
5. Add images only when they support trust or step-by-step clarity:
   - product screenshots for tutorial steps,
   - official-source screenshots for credibility/explanations,
   - avoid decorative stock images.
6. Include a final publishing support section when useful:
   - asset upload table,
   - source notes,
   - internal link table.

## Output Rules

- If the user asks for "像这个一样", "WordPress copy page", "可以复制到 WordPress", or a complete publish package, output a full HTML copy page using the reference pattern.
- If the user asks for article text only, output the publishable article body without yellow guide boxes.
- If optimizing an existing article, preserve correct facts and user intent, then improve:
  - opening quick answer,
  - trust explanation,
  - tutorial clarity,
  - FAQ coverage,
  - internal links,
  - image alt/caption plan,
  - SEO title/meta/slug.
- For English target articles, write the article body in natural English; keep editor notes in Chinese if delivering a copy page for this user.
- Do not invent official support, API routes, pricing, availability, dates, or discontinuation claims. Browse or ask for sources when current facts matter.

## Required Reference

Read `references/copy-page-pattern.md` before creating a full WordPress copy page, rebuilding a blog template, or optimizing an article into this style.

For light edits, title/meta suggestions, or small FAQ additions, this SKILL.md is enough.
