## Manual Sync

Pull this repository into local Codex skills:

``powershell
.\pull-to-codex.ps1
``

Push local Codex skill edits back to GitHub:

``powershell
.\push-from-codex.ps1
``

Scripts intentionally exclude .system/, Python caches, .env*, and logs.
